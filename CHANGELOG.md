# Changelog

## V_0_2 – 2026-11-25
- Step-by-step guide for enabling USB debugging, with menu paths per phone brand
- Plain-language status messages with "what to do" steps for all connection problems
- Explanation and fix shown under each failed file (~20 Android install error codes)
- APK pre-check: detects bundles (.apks/.xapk/.aab), broken downloads, saved web pages, wrong processor type
- New option "Allow very old apps" (Android 14+), clearer option descriptions
- Cancel button while connecting; hint if the "Allow USB debugging?" dialog is not confirmed
- Installation summary, Copy log button, Troubleshooting section
- Automatic fallback to copy & install when streamed install is not available

## V_0_1 – 2026-11-25
- First version: ADB over WebUSB, RSA authentication, streamed install (Android 7+) and push + pm install (older), multiple files, uninstall
