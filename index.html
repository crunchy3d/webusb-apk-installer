APK Installer

Install Android apps (.apk files) on a phone connected by USB cable – directly from this page, no extra software needed.
📱 First time? Prepare the phone (enable USB debugging) – takes 2 minutes
USB debugging is a hidden setting that allows a computer to install apps. You only need to turn it on once. Choose your phone brand for exact menu names:
    Menu names differ slightly between Android versions. If you can't find an item, use the search field at the top of the Settings app and type e.g. “build number” or “USB debugging”.

    1Connect the phone

    Not connected
    Plug in the phone with a USB cable, unlock its screen, then click Connect phone and select it in the window that opens.

    2Choose apps to install

    Drag .apk files here, or click to choose files
    Remove an app from the phone (optional)
    Only apps you installed yourself are listed. Uninstalling also deletes the app's data.
    Troubleshooting
    My phone is not in the list after clicking “Connect phone”.
    USB debugging is probably off (see the guide above), the cable only charges (try another cable – many cheap cables have no data wires), or on Windows a driver is missing. Unplug and re-plug the cable and unlock the phone screen.
    The phone never shows “Allow USB debugging?”.
    Unlock the screen and look at the notification area. In Developer options tap Revoke USB debugging authorizations, turn USB debugging off and on, re-plug the cable, and connect again.
    “The phone is being used by another program”.
    Only one program can talk to the phone at a time. Close Android Studio, scrcpy, phone-manager software (Samsung Smart Switch, Mi PC Suite, …) and any other tab with this page. If you use adb, run adb kill-server in a command prompt.
    Windows: phone does not appear at all.
    Install the USB driver of your phone maker (e.g. Samsung Android USB Driver, Google USB Driver for Pixel), then re-plug the phone.
    Linux: “Access denied”.
    Your user needs permission for USB devices: install the android-sdk-platform-tools-common (Debian/Ubuntu) or android-udev package, add yourself to the plugdev group, then log out and in again.
    Which files can I install?
    Single .apk files. App bundles (.apks, .xapk, .aab) consist of several parts and are not supported by this page.
