Help / troubleshooting
  • On the phone: Settings → About phone, tap Build number 7×; then Developer options → USB debugging ON.
  • Connect the phone with a data USB cable, click Connect phone and pick it in the list.
  • The first time, the phone shows “Allow USB debugging?” – tick Always allow and tap Allow.
  • “Unable to claim interface” / “Access denied”: another program is using the phone. Close Android Studio / scrcpy and run adb kill-server.
  • Windows: if the phone is not listed, install the Google USB Driver (or the phone maker's ADB driver) so the ADB interface uses WinUSB.
  • Some phones (e.g. Xiaomi) also need Install via USB enabled in Developer options.
  • Split APK bundles (.apks / .xapk / .aab) are not supported – only single .apk files.
